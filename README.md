# Video Production Playbook

My open collection of templates and checklists for producing AI-assisted video content — the system I use to take a video from idea to published.

## Why I built this

I produce AI-assisted video content, and I kept losing track of production steps when moving between research, scripting, voiceover, visuals, and editing tools. Steps got skipped, videos shipped half-planned, and every project felt like starting over.

So I wrote the workflow down. This playbook is the pipeline I actually use: one brief template, one script structure, and checklists for research and publishing. Now every video runs the same system, no matter which tools I use that month.

## What's inside

- `templates/production-brief-template.md` — the starting document for every video: topic, angle, audience, research questions, and production notes.
- `templates/script-template.md` — my script structure: hook, setup, body beats, close, with voiceover and visual notes built in.
- `templates/research-checklist.md` — what "done researching" means before I'm allowed to start scripting.
- `templates/publishing-checklist.md` — everything that must be true before a video goes live.
- `examples/finnish-classrooms-brief.md` — a worked example: a filled-in production brief for a real video topic from my documentary series.

## How I use it

1. Pick a topic and fill in the production brief template (30 minutes).
2. Work the research checklist until every box is honestly checked.
3. Draft the script from the brief using the script template — I draft with an AI writing assistant, then rewrite in my own voice.
4. Produce audio (text-to-speech voiceover, directed for tone and pace), generate visuals against the script beats, edit, mix in royalty-free music and sound effects.
5. Run the publishing checklist, then ship.

## What I learned

- Documenting a process turns experimenting into a repeatable capability. Tools change constantly; a written workflow survives tool churn.
- Writing templates forces you to get specific: "do good research" is a wish, a checklist of eight questions is a standard.
- Markdown and repo organization basics — structuring files so a stranger (like a recruiter) can understand the project in five minutes.
- The workflow is the real skill. AI is strongest when each tool does one job inside a system I designed.
